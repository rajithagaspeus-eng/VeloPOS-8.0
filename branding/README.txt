YOUR LOGO AND WINDOW ICON
=========================
Put your files in THIS folder (branding, next to run.py) with exactly these names, then close VeloPOS and open it again:

    dev_logo.png    -> your logo, shown BIG on the Login, About, Activate and first-run Setup screens
                       (a PNG with a transparent background looks best; the height is set by the screen, the shape is kept as it is.
                        If this is missing, logo.png / logo.jpg is used, and then app_icon.ico.)
    app_icon.ico    -> the small icon in the window's title bar and on the Windows taskbar

* Without a logo the screens keep their normal text titles.
* This folder goes INSIDE the zip you give to customers (it holds only pictures).
* Sizes (pixels high): Login 150, About 160, Activate 90, Setup 110 - ask the developer if you want them bigger or smaller.
* The logo printed on RECEIPTS is separate: Settings -> "Upload shop logo".
